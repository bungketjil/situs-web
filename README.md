# Situs Web Belajar

Portofolio dan proyek latihan saya saat belajar HTML, CSS, dan JavaScript.

Lihat langsung: https://bungketjil.github.io/situs-web/

## Proyek
- **Kalkulator**: dukungan keyboard dan riwayat perhitungan
- **Cuaca**: data dari Open-Meteo, perkiraan 3 hari, dan lokasi GPS
- **Kuis Web**: soal diacak, timer, dan skor tertinggi
- **Tebak Angka**: game sederhana dengan JavaScript

## Teknologi
HTML, CSS, JavaScript, Git, GitHub Pages
